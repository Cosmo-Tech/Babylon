# CLI reference

This is the single command and option reference, generated from the commands
registered by the installed Babylon version. Workflow examples are available
in the [tutorials](../tutorial/index.md).

Use `babylon <command> --help` for the same information in your terminal.
Power BI deployment is supported through the `init`, `apply`, and `destroy`
macros; no standalone `powerbi` group is exposed.
