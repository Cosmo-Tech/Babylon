# Examples

These examples build on [configuration](../getting_started/configuration.md) and
the [deployment tutorial](../tutorial/deploy.md).

- [Deploy a project](deploy.md): customize the generated variables and manifests.
- [Update access controls](update.md): change API object security consistently.
- [Deploy Superset dashboards](superset.md): import ZIP exports and configure embedding.
- [Deploy Power BI dashboards](powerbi.md): publish PBIX reports and configure permissions.
- [Delivery Brewery](delivery_brewery.md): use the standard project repository.

All examples use the same [CLI reference](../references/cli.md) and
[state model](../guides/state.md); they are not separate installation or command
reference guides.
