# Tutorials

Follow one supported workflow with the CLI installed from this repository:

1. [Install Babylon](../getting_started/installation.md).
2. [Configure authentication and select a namespace](../getting_started/configuration.md).
3. [Deploy a workspace](deploy.md) using generated manifests.
4. [Work with an existing organization and solution](existing_resources.md)
   through the API commands.
5. [Destroy a deployment](destroy.md) when it is no longer needed.

The [examples](../examples/index.md) show practical variable files, access
controls, and dashboard configuration. The [CLI reference](../references/cli.md)
is generated from the commands actually registered by this version of Babylon.
